# Пресет для бенча

Цель — готовый и закоммиченный пресет за 4–6 вызовов инструментов. Код fleet и сервиса, `docs/ARCHITECTURE.md`,
README и задачи датасета **не читать**: всё нужное печатает разведка. Браузер, S3 и кластер не трогать без просьбы.

## Шаги

1. **Разведка — один вызов.** Аргументы `модель=`, `агент=`, `задач=`, `ref=`, `имя=` перевести во флаги:

   ```bash
   uv run python -m fleet_console.presets.scout <бенч> [--model M] [--agent A] [--tasks N] [--ref R] [--name P]
   ```

   Скрипт читает зеркало сервиса `~/.fleet-console/fleet.git` на ревизии `--ref` и печатает: группу `harbor/dataset`,
   записи реестра `datasets/`, эксперименты fleet с этим бенчем, ветки с его именем, предупреждения `⚠` и черновик YAML.

2. **Разобрать вывод.**
   - Код 1 и «нет ни группы, ни записи реестра»: в ревизии бенча нет. Перечислить найденные ветки и спросить
     пользователя, какую взять (`--ref <ветка>`). Самому по веткам не искать.
   - «кандидатов несколько»: повторить с точным именем из списка (имя записи реестра или группы).
   - «не годится» про группу: это нормально, скрипт уже взял реестр. Упомянуть одной фразой.
   - «агент … не из эксперимента»: передать пользователю как риск.
   - Дата обновления зеркала старше пары дней: сказать. Обновляет пользователь кнопкой «Актуализировать» в шапке.

3. **Записать.** Тот же вызов с `--write`. Существующий файл скрипт не перезаписывает: при занятом имени передать
   `--name <другое>` или спросить пользователя.

4. **Проверить:**

   ```bash
   uv run pytest -q tests/test_presets.py tests/test_scout.py
   ```

   `test_repo_presets_load_and_fit_master_groups` загружает все файлы `presets/`, битый пресет его роняет.

5. **Закоммитить** в текущую ветку одним коммитом: `presets: <имя> — <датасет> × <агент>, <N> задач`.

6. **Ответить** коротко: имя пресета; модель, агент, датасет; предупреждения разведки. Напомнить, что в форме
   «Запустить бенч» после выбора пресета первым делом нажимают «Превью и preflight». Если задач нет на диске,
   под ошибкой preflight будет «Скачать из S3». «Запустить» жмёт пользователь сам.

## Что скрипт решает сам

- Есть годная группа `harbor/dataset`: пресет ссылается на неё по имени. Фильтр `task_names` в группе снимается
  override `harbor_job.datasets.0.task_names=[]`, иначе smoke на N задачах прогонит одну.
- Группы нет или она с абсолютным путём `/data/<user>/…`: датасет задаётся путём под `FLEET_DATASETS_ROOT` и записью
  реестра. `benchmark` — короткое имя бенча из `[a-z0-9-]`: fleet кладёт его в имя workflow Argo без очистки,
  а метку результатов берёт из реестра.
- Агент — из эксперимента fleet с этим бенчем, сначала с той же моделью, потом с меньшим числом бенчей.
- Модель по умолчанию `qwen36_35b_a3b` на 1 GPU, `served_model_name` с суффиксом `-console`; 1 реплика,
  агентов на реплику столько же, сколько задач.

## Шаблон промпта

```
/bench-preset cowork
/bench-preset terminal-bench задач=5
/bench-preset swe_bench_verified модель=checkpoints_qwen_262k агент=terminus2 имя=ckpt-swe-smoke
```

Без слэша: «Собери пресет для бенча `<имя>` по навыку bench-preset, задач `<N>`, закоммить».
